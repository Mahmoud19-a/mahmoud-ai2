# لوحة (Lawha): محرر تصاميم مجاني

محرر تصاميم مجاني بالكامل يعمل على الآيفون والآيباد بدون إنترنت وبدون حساب.
فيه قوالب، نصوص عربية بخطوط جميلة، أشكال وأيقونات، صورك الخاصة، صفحات متعددة، وتصدير PNG / JPG / PDF.
الميزات التي تكون مدفوعة في تطبيقات أخرى (تغيير المقاس، الخلفية الشفافة، ألوان وخطوط علامتك) مجانية هنا.

## تنزيل ملف IPA وتثبيته بـ SideStore

1. افتح صفحة **Releases** في هذا المستودع على GitHub (أو تبويب **Actions** ← آخر تشغيل ← `Lawha-ipa`).
2. نزّل ملف `Lawha.ipa` على الآيفون.
3. افتح **SideStore** ← تبويب **My Apps** ← زر **+** ← اختر `Lawha.ipa`.
4. SideStore يوقّع التطبيق بحساب Apple الخاص بك ويثبّته. التوقيع المجاني يحتاج تجديداً كل 7 أيام (SideStore يجدده تلقائياً).

كل دفعة (push) على مجلد `web/` أو `ios/` تبني نسخة جديدة تلقائياً.

## تجربة التطبيق على الكمبيوتر

افتح `web/index.html` مباشرة في المتصفح. لا يحتاج سيرفر.

## بنية المشروع

| المجلد | المحتوى |
| --- | --- |
| `web/` | المحرر نفسه (HTML/CSS/JS + Konva + jsPDF + الخطوط والأيقونات) |
| `ios/` | تطبيق iOS بسيط (Swift + WKWebView) وملف XcodeGen |
| `.github/workflows/ios.yml` | يبني ملف IPA غير موقّع على GitHub (Mac مجاني) |
| `replica/` | خريطة التحليل، مصفوفة الميزات، وملاحظات البناء |
| `.claude/skills/` | مهارات Replica |

## التراخيص

- الكود: من كتابة هذا المشروع.
- Konva وjsPDF: رخصة MIT.
- أيقونات Lucide: رخصة ISC.
- الخطوط: Google Fonts برخصة OFL.

ملفات الترخيص موجودة في `web/vendor/` و`web/fonts/`.
القوالب والأيقونات والاسم كلها أصلية، ولا يوجد أي محتوى أو شعار من Canva.
